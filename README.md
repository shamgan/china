# טיול למרכז סין — אלבום תמונות

אתר גלריה סטטי המציג תמונות נבחרות מהטיול לרמת טיבט ומרכז סין, מחולק לקטגוריות (מפות, גיאוגרפיה אנושית, גיאוגרפיה פיסית), עם אפשרות להגדיל כל תמונה ולקרוא את הכיתוב שלה.

מתארח ב-GitHub Pages: https://shamgan.github.io/china/

## מבנה

- `index.html` — מבנה הדף
- `styles.css` — עיצוב
- `script.js` — בניית הגלריה מתוך `data.json` ולוגיקת התצוגה המוגדלת (lightbox)
- `data.json` — רשימת התמונות, קטגוריה וכיתוב לכל תמונה
- `images/` — קובצי התמונות

## עדכון תוכן

כדי להוסיף, להסיר או לערוך תמונה — עורכים את `data.json` ואת תיקיית `images/` בהתאם. אין צורך בבנייה (build) כלשהי, האתר סטטי לחלוטין.
